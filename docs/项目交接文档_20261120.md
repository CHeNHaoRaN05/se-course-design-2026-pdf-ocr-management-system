# 项目交接文档（2026-11-20）

## 1. 交接背景与最终决策

本项目为《基于本地 OCR 的 PDF 文件显示与管理系统》课程设计。由于进度落后，经裁剪决策，**项目范围收敛为「最小必须功能集」**：

> **最小必须功能集 = 文档的上传、下载、显示、管理 + OCR 识别链路跑通。**

OCR 只要求链路能跑通（提交任务 → 识别 → 回写 → 导出/检索），不承诺准确率指标；未实现的中级/高级功能一律列为范围外，不视为待办或交付承诺。

本交接文档说明四件事：最终保留什么、砍掉了什么、最小集当前实现了多少、设计文档 2.0 在哪里以及如何使用。

## 3. 砍掉的功能（范围外，不视为待办）

以下功能在 V1.0 设计文档或需求文档中出现过，但**V2.0 明确不做**，不进入验收、不视为漏做。统一清单见 V2.0 主文档 5.3.16。

### 3.1 阅读器高级交互
- 连续 / 单页模式、适应宽度
- 缩略图侧栏、目录大纲
- 页内搜索与命中高亮
- OCR 文本层叠加（可选中复制）、原文 / 识别文本双视图
- 阅读位置记忆
- 批注修改 / 撤销

### 3.2 文件管理高级
- 独立分类树（自引用层级、禁环、标签颜色）
- 文件版本与代次（版本列表、回滚、分支树）
- 标签多对多（V2.0 简化为文件夹字符串路径）

### 3.3 OCR 高级
- 结果校对（逐框改字、`expected_revision` 乐观锁、409 冲突、撤销）
- 表格还原（规则线框还原、手工修正、无线框降级）
- 语言 / 方向检测、低于 150 dpi 质量提示、手写模式专用 YOLO 权重
- 流式导出

### 3.4 检索高级
- 按文件 / 时间 / 标签过滤
- 检索历史
- 阅读器页内命中高亮（结果片段高亮保留）

### 3.5 配额、统计与运维
- 用户可见配额管理：写接口、容量上限、超额拦截（429）、统计看板
- 审计日志 180 天保留 / 归档作业（查询能力保留）
- 200 页标注集 ≥90% 准确率评测、10 万页 P95 性能压测
- 生产部署脚本（Docker / nginx）、长期负载 / 恢复演练 / 数据迁移

### 3.6 配额裁剪的特殊处理

配额采用「**砍前端与用户可见能力，保留底层记账**」策略：
- 保留：`ocr_before_enqueue` 默认空实现、`settle_terminal`、`quota_accounts` / `quota_ledger` 的按页记账逻辑、契约 C3 的内部记账语义。
- 砍掉：配额写接口、容量上限、超额拦截、统计看板。
- 原因：删除底层记账会破坏 OCR 任务结算链路，引起回归。
