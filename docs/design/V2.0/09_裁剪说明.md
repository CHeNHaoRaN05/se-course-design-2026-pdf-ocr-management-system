# 设计文档裁剪说明（2026-11-19）

本次只改文档，**未动任何代码**。目标：让设计文档与「最小必须功能集 = 文档上传/下载/显示/管理 + OCR 能跑通」一致，把未实现的中级/高级功能显式列为范围外。

## 一、统一口径

所有改动文档统一引用 `docs/features.md` 1.2 的**范围外清单**，涵盖：
- 阅读器高级：连续/单页模式、适应宽度、缩略图、目录大纲、页内搜索高亮、OCR 文本层、位置记忆、批注改/撤销
- 文件高级：独立分类树、版本代次、批量操作条、合并/拆分（注：代码在 PR #9 已合入 main（2026-11-21））、流式导出
- OCR 高级：校对、表格还原、语言/方向检测、<150dpi 提示、手写模式、无框线降级
- 检索高级：过滤、历史、页内高亮
- 配额与运维：写接口、容量上限、超额拦截、统计看板、审计保留作业、200 页评测、生产部署

配额的处理采用「**砍用户可见能力、保留底层记账**」：`ocr_before_enqueue`、`settle_terminal`、C3 契约保留为 OCR 内部按页记账，不承诺配额看板/容量/超额。
