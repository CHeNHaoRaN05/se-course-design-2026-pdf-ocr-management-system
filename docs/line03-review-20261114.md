# 03 线审查修订（2026-11-14）

基线：main 8cf647f。报告中的 docs/contracts/C1–C5 路径在此版本并不存在；本文件记录本次跨线行为变更，需陈、岳审阅后合并。

## 接口与事务约定

- 生产 API 必须通过宿主挂载，主 JWT 强制 jti/tv；独立 API 仅允许显式开发模式，开发令牌使用隔离 audience。
- 宿主直接注入同库、同存储、同密钥、issuer/audience 与上传上限，不修改进程环境。宿主上传统一走 /files。
- 配额预留绑定任务 ID 与预留月份，worker 终态、取消、删除均在事务中结算。宿主定期补结旧终态任务，前端 settle 仅作幂等补偿。
- 取消全额退款，其他终态成功页计费。retry 返回新任务 ID，仅重试失败页；调用者须使用响应 ID。
- 在锁定账户后检查关闭流水，关闭标记采用确定性主键，不新增数据库字段。
- 删除在同一数据库事务中取消、退款、删除索引及任务；物理文件在 commit 后清理，失败记录日志。
- 主鉴权、配额、文件生命周期涉及 01/02 线，PR 需跨线审阅。未变更数据库 schema，无需重建开发库。

## 验收边界

测试结果与逐项处置见本文后续记录。不得以替身推理或 SQLite 测试宣称真实 Paddle、MySQL 或 200 页准确率验收通过。

## 兼容性与交付

无需 schema 迁移或重建数据库。缺少 jti/tv 的旧 token 会失效，需要重新登录。独立 API 仅用于隔离开发；生产继续用宿主挂载方式。调用 /jobs/{id}/retry 的外部客户端必须采用响应中的新任务 ID。

本次只向新的修复分支提交；共享配置/JWT/配额由 01 线、文件生命周期与回收站由 02 线审阅，审核通过再合并 main。
