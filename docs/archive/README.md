## 版本判定口径

以 docx 内部 `docProps/core.xml` 的 `dcterms:modified` 为准，**不用文件系统时间**——仓库检出一致化后，所有文件的 mtime 会被重写为同一时刻，不具备区分力。

## 使用约定

- 归档文件只读，不再修改；需要复用时另存到 `docs/design/` 或 `docs/requirements/`。
- 重新导出 Word 请用 `scripts/export_design_docx_v2.py`（系统设计 V2.0）与 `scripts/export_req_docx.py`（需求 V1.1），输出路径写死在这两个脚本里。
