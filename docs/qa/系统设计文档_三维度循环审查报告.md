## 五、已核查但不判错的观察项

- 表 6-2 / 6-4 的「表题 + 表注 + 表格」间距为规范结构；界面原型 20 张图顶部带 UI 标题栏，属成图内容而非旧图题回归。

- 文档沿用课程模板「概要设计说明书」命名但含详细设计深度，已在 1.1 说明覆盖范围；独立测试设计章节、接口逐条参数规格、监控指标实现属扩写或后续演进项，按 `docs/qa/系统设计文档_收敛审查报告.md` 的既有约定不纳入本次循环。
