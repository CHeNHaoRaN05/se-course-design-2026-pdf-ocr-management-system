## 真实服务联调

使用 Python 3.12.16 和仓库 `pdf_system/requirements.txt` 安装的依赖。API 由 `scripts/start-smoke-api.py` 启动，使用临时目录、独立随机 JWT 密钥、独立 SQLite 和存储，不读取项目 `.env`，OCR 在配置中关闭。

浏览器直接访问 Vite 和上述真实 API，未设置 API 请求拦截器，验证：

1. 注册新账号、登录、获取账号信息。
2. 上传两份真实 PDF，设置分类和标签，重新读取文件列表。
3. 合并为四页 PDF，再按两段拆分，服务端校验并保存新文件，原文件保留。
4. 创建 7 天有效且带提取码的分享，独立未登录浏览器通过提取码下载正确文件。
5. 撤销分享，访客再次访问被拒绝。
6. 文件软删除，浏览器记录回退，调用真实还原接口，文件恢复到列表。
7. 读取真实文件数量与配额统计。
8. 修改密码，轮换当前 JWT，登出。

测试账号、密码和 JWT 不写入源码或验证报告。临时 API 停止后测试数据库和文件清理。

## 浏览器契约测试

17 项浏览器用例使用页面级夹具，覆盖真实服务联调之外的边界：

- 登录返回来源页面、注册确认密码校验。
- 整体列表排序 / 分页、搜索、列表和卡片切换。
- 取消删除保留选择、删除与还原、批量操作部分失败。
- 上传文件头校验、超过 20 MiB 的请求前拦截、元数据保存失败重试不重复上传。
- 合并和拆分上传新文件。
- 分享提取码错误、仅元数据模式、公开请求不带当前 JWT、撤销二次确认。
- viewer 写入口限制、管理员路由守卫。
- 搜索高亮与文本转义、检索历史清空。
- 按 ID 管理用户、缺失接口的明确提示，以及扩展接口补齐后的列表显示。
- 401 清除凭据、跨标签页退出同步、改密后反馈和账号保持。
- 窄屏导航和无页面横向溢出。
