## 真实服务联调

使用 Python 3.12.16 和仓库 `pdf_system/requirements.txt` 安装的依赖。API 由 `scripts/start-smoke-api.py` 启动，使用临时目录、独立随机 JWT 密钥、独立 SQLite 和存储，不读取项目 `.env`，OCR 在配置中关闭。

浏览器直接访问 Vite 和上述真实 API，未设置 API 请求拦截器，验证：

1. 注册新账号、登录、获取账号信息。
2. 上传两份真实 PDF，设置分类和标签，重新读取文件列表。
3. 初版在浏览器合并为四页PDF并拆分，服务端只校验上传输出；不代表初版已有服务端合并拆分。
4. 创建 7 天有效且带提取码的分享，独立未登录浏览器通过提取码下载正确文件。
5. 撤销分享，访客再次访问被拒绝。
6. 文件软删除，浏览器记录回退，调用真实还原接口，文件恢复到列表。
7. 读取真实文件数量与配额统计。
8. 修改密码，轮换当前 JWT，登出。

测试账号、密码和 JWT 不写入源码或验证报告。临时 API 停止后测试数据库和文件清理。
